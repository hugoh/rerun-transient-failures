# Built-in transient / infrastructure failure signatures.
# One Python regex per line. Blank lines and #-comments are ignored.
# Matching is case-insensitive and searched anywhere in the failed-job log.
#
# Keep these HIGH-CONFIDENCE: a false positive silently burns a rerun, while a
# false negative just means a human retries by hand. Add project-specific
# entries via the action's `patterns-file` input instead of editing this file.
#
# NOT covered by design: flaky tests. An intermittently-failing test should be
# fixed or quarantined, not auto-retried — auto-retrying masks the bug. Add a
# `patterns-file` entry if you really want that for a specific suite.
